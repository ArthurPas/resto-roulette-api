# Restoroulette API
RestoRoulette est une app qui aide à répondre à une question aussi courte que chronophage : “Qu’est ce qu’on mange ?”.
Le dilemme est souvent sans  ~~faim~~ fin, particulièrement lorsqu’on est plusieurs à devoir se mettre d’accord. 
Le principe est donc de proposer une application mobile qui, aussi rapidement que possible, aide à trouver le restaurant qui conviendra à tous. 
Avec un système de swipe rapide et intuitif sur les types de cuisines, d'algorithmes de sélection basés sur des critères définis à l’avance, et une roulette aléatoire finale parmi les restaurants qui correspondent le plus au groupe
, le choix est rapide et efficace. En complément, l’application propose une expérience de réseau social culinaire pour recommander des restaurants à son réseau. Ce document présente l'ensemble des éléments liés à la gestion au sens large de ce projet
par notre équipe.


- Back-office web et app mobile
- Gestion d'un réseau social
- Serveur d'image
- Base de données de restaurateur, restaurants, utilisateurs
- Temp réél par websocket
